## Build Your Own Portfolio

If you arrived here after seeing my portfolio and would like to build something similar, you are welcome to use the website structure as a starting point.

The two main files are:

- **`index.html`** — website content and page structure
- **`styles.css`** — layout, typography, colors, responsive behavior, and visual styling

You do not need to be a web developer to customize the site. Most changes involve replacing text, links, images, and project information in `index.html`.

### Basic Workflow

1. **Fork or clone this repository**
2. Replace the content in `index.html` with your own information
3. Customize the design in `styles.css`
4. Replace the images and technical graphics with your own
5. Add links to your projects, publications, résumé, LinkedIn, and GitHub
6. Enable **GitHub Pages**
7. Publish your portfolio

Once GitHub Pages is enabled, your website can be hosted directly from the repository at no hosting cost.

## GitHub Pages

GitHub Pages can publish a static website directly from a GitHub repository.

For a personal GitHub Pages site, the repository is typically named:

```text
yourusername.github.io
```

The resulting website is then available at:

```text
https://yourusername.github.io/
```

GitHub Pages documentation provides instructions for enabling Pages and selecting the appropriate deployment branch.
